# 已知限制

更新日期：2026-11-17。原交付時「無逐日 NAV、新聞無標題、V2.11 克隆截止 11/09、V3 無淨值」描述的是當時交付來源，不再概括目前整合後的主站。舊驗收與歷史快照保留原樣；網站以選取的正式來源或合成 DEMO 即時讀檔。

## 目前已有的展示來源

- V2.11 正式保存帳本已有 11/06 至 11/17 的 8 個估值日，包含模型與相同政策等權的 `NAV_Open`、成本及股票／現金曝險。主站補上同期間淨值、相對財富、回撤與權重圖，不再稱「所有 V2 都沒有逐日 NAV」。
- 共用新聞展示 metadata 已有 42 筆標題與網址；V2 原始快取的 46 筆仍無標題欄位。兩者須以原始鍵與來源對應，不能推測補齊，更不能作為歷史已取得新聞的證明。
- V3 已有保存研究帳本衍生的淨值與 0050 比較圖。各版本保留原研究期間、成本及探索性狀態，不與 V2 不同協議直接排名。原交付所列 006204 含息淨值缺口，沒有因此被認證為已補齊。

## 仍然存在的限制

- 歷史 V2 比較的各折模型權重未保存，彙總報告不包含可重建完整日路徑的資料；不能將目前 V2.11 的 8 日帳本冒充歷史多年的逐日 NAV。取消 Risk-Off 的同預測配對帳本也未因此新增。
- V2.11 使用分數股、比例交易費及股票賣稅，無最低手續費、滑價及 V3 的完整公司行動會計。其 `NAV_Open` 仍持有股票，與 V3 扣末日整股清算費的績效口徑不同。最新末日假設平倉費另列，不把它當成已實付費用；歷史 `Liquidation_If_Closed` 欄也不是連續每日清算曲線。
- V2 同期、同成本／成交規則的 0050 含息帳本仍缺。相同政策等權才是目前可用的配對基準，不能改名為 0050 或借用 V3 不同期間曲線。
- 完整真實 Ridge 私有帳本、原始輸入版本及 receipt／CHAIN 尚未交付；正式來源顯示 `DATA_UNAVAILABLE`。舊交付快照與合成 DEMO 不補入正式績效。
- 歷史新聞、訊號的可得／發布時間證據仍不足。檔案雜湊、推論完全一致及測試通過不等於 point-in-time 已認證；V2 帳本仍標示 `historical_availability_certified=false`。
- 截至此快照只有 3 個成熟五日訊號日、15 筆股票觀測，同日股票相關且標籤重疊；不宣稱獨立前瞻 alpha、新聞增益或已超越 0050。沒有券商連線，帳本成交是模擬成交。

主站讀取 GitHub 每日流程已保存的資料，五分鐘重讀不等於自行重訓、補造資料或執行券商交易。正式與 DEMO 來源分開，也不將舊交付克隆、當期正式帳本接成同一條績效。
