## 本輪補了什麼

V2 與 V3 使用相同的六個頁籤：**結果總覽、預測與驗證、成本與風險、每日運作、優化實驗、來源與限制**。淨值、相對基準及回撤採共用的原生互動圖表，可查看日期與數值；配對長條圖沿用相同單位、顏色及滑鼠提示。統一的是閱讀方式，各版本仍保留各自的研究協議、期間與基準。

## 相同介面下仍保留的協議差異

| 項目 | V2.11 | V3.3／V3.4 現行研究 |
| --- | --- | --- |
| 可用的配對基準 | 相同政策等權、相同風險上限 | 0050 與配對價格模型 |

| 標籤／再平衡週期 | 五日標籤／每五個交易日排程 | 二十日標籤／每二十個交易日排程 |
| 股數及成本 | 分數股；比例手續費 0.1425%、股票賣稅 0.3%；無最低手續費及滑價模型 | 整數股；最低手續費 20 元；5bps 單邊滑價及 15bps 壓力測試；股票／ETF 賣稅分列 |
| 主要績效結算 | `NAV_Open` 仍有持倉；末日假設平倉另列 | 依各版本協議扣除末日整股清算費，零股權益另列 |
| 資料期間 | 顯示 V2 保存帳本的日期 | 顯示各 V3 研究保存期間 |

V2 的 `Liquidation_If_Closed` 在重播末日估計，舊資料列可能保留當時末日的估計；不可將整欄當成每日實際支出或連續平倉曲線。本輪主曲線使用 `NAV_Open`，只將來源最新末日的假設清算值另列。

歷史 V2 實驗摘要仍可展示：`reports/v210_comparison/comparison.json` 保存 rolling_selected ROI **25.407473%**、相同協議等權 **27.047171%**，差 **-1.639698 個百分點**。這是另一段歷史研究，不與當期 V2.11 接成同一條績效，也不與 V3 不同期間直接排名。

## 仍缺少什麼

| 缺口 | 為何本輪不能補造 | 目前如何呈現 |
| --- | --- | --- |
| 完整真實 Ridge 前瞻帳本、原始輸入版本與 receipt／CHAIN | 交付包未包含完整私有證據鏈；舊快照數字或 DEMO 不能替代 | 正式來源顯示 `DATA_UNAVAILABLE`，保留缺口及驗證條件 |
| 歷史 V2 walk-forward 各折模型權重及完整逐日 NAV | `comparison.json` 明示 `weights_saved=false`；彙總指標無法重建原權重與日路徑 | 展示已保存的彙總／fold 指標，歷史日曲線顯示缺失 |
| 歷史新聞及訊號的 point-in-time 可得證明 | 保存檔案 hash 與推論一致只能確認內容，不能證明當時已取得／已發布；帳本明示 `historical_availability_certified=false` | 明示歷史可得性未認證，保留探索性狀態 |
| V2 同期、同成交與成本規則的 0050 含息帳本 | V2 保存行情只有五檔股票及 `^TWII`；V3 的 0050 曲線期間與成本規則不同 | V2 使用真正可配對的相同政策等權，不改標為 0050 |

新聞展示方面，共用 `data/news_display_metadata.jsonl` 在此快照有 **42 筆標題及網址**；V2 `market/news_cache.csv` 的 **46 筆快取**仍沒有標題欄位。可展示已保存、可對應的共用新聞 metadata，不能猜測補齊全部 V2 標題，也不能將後來取得的標題當成歷史可得證據。

本輪補齊的是展示、對帳、誤差診斷及證據透明度。原研究結果沒有因此改寫，V2 仍未證明超越 0050，V3 仍依原採用門檻維持探索及基準方案。
