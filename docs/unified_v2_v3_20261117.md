# V2整合至完整專案網站與首輪優化

入口仍為`dashboard/app.py`，Python3.12與現有輕量展示依賴不變。側欄新增「V2研究」，原444、555、新聞、日誌、文件及V3均保留；無須另外部署第二個網站。

## V2如何使用

預設「正式保存資料」直接讀取GitHub每日保存的V2.11訊號、registry與模擬帳本；可看V2.11、交易日誌、當日檢討、隔日策略、歷史實驗及優化診斷。獨立的合成DEMO須手動選擇，前瞻資料與日誌明標SYNTHETIC_DEMO，不會補入正式來源或影響其他使用者。完整Ridge私人帳本未交付，Saved模式顯示DATA_UNAVAILABLE。

兩種來源以每次頁面讀取的獨立設定隔離，不改程序全域環境；不同使用者與分頁同時操作不會混到來源。網站沿用五分鐘整頁重讀，正式資料隨既有每日流程與GitHub同步更新。已成熟的11/09標籤到隔日早上也不會因時鐘重新變為未成熟。

「優化診斷」核對帳本hash、五檔完整原訊號及五日成熟標籤，並用相同股票列比較模型／零預測。2026-11-17保存的3個成熟訊號日共15列：MAE4.6982對4.7913，改善0.0931個百分點，方向準確率73.33%對46.67%。這不是15個獨立時間樣本，也不是交易勝率、新聞增益或已勝過0050的證明。

原凍結權重與發布訊號不變。下一個V2模型版本的有限候選、時間切分與新聞殘差設計見[V2研究計畫](v2_next_research.md)。

## V3已執行的優化

「V3研究 → 優化實驗」展示V3.4。固定V3.3已保存的Ridge價格／新聞預測，對照原配置與實際增量成本配置；相同日期、80／20配置、費率、20日排程、次日收盤與15bps壓力。完整三折與留出舊配置先重播一致，沒有重訓或以留出選策略。

2026-04-15～11-09，新配置新聞成本從11720.9979降至9158.0744元，但淨報酬從13.0049%降至12.4340%，0050為15.9048%；同配置新聞還低於價格控制0.4604個百分點。三折仍只一折正超額，維持B0，不採用新配置作已改善模型。

降低成本改變了持倉與現金路徑，不能把省下費用直接加回就宣稱勝出。下一輪先處理公司專屬事件、去重與價格模型樣本外殘差；需有可追溯新聞資料，不反覆調原留出直到出現贏家。[設計](../research/v3_4/design.md)及[完整結果](../reports/research_v3_4/2026-11-17/summary.md)。

## 保留與限制

原V2增量交付、合成fixtures及獨立入口仍可查看；主站不呼叫獨立App的main，也不套用其深色全域主題。原研究、凍結權重、model card、Scaler與舊訊號不改寫。新V3原始行情與詳細帳本仍在私人工作目錄，Git只放衍生指標、設定及來源hash。

全部已查看歷史維持探索性。缺少舊發布證據、完整Ridge收據鏈與原五股選定證據的限制仍存在，不能因網站整合、hash或測試通過而稱為前瞻alpha。

本次驗證：原站、V2增量、來源隔離、診斷與新成本實驗合併共542項測試通過。來源模式以雙執行緒交錯測試，正常／例外離開後均恢復，沒有全域環境或檔案修改。凍結NPZ、model card與完整bundle雜湊維持原值；新實驗執行前後原私有輸入及登記來源hash一致。
