# V2下一輪：先檢查預測增量，再改模型

目前凍結權重與已發布訊號維持原樣。網站的「V2研究 → 優化診斷」以每日保存的成熟五日標籤，比較原預測與永遠預測0%的同列誤差；不重訓、不用這些結果選門檻。

截至2026-11-17，只有11/05、11/06、11/09三個成熟訊號日、15筆股票列。模型MAE約4.6982個百分點，零預測約4.7913，改善約0.0931個百分點；方向準確率約73.33%與46.67%。相鄰五日標籤重疊、同日五股相關，這不是15個獨立時間樣本，也沒有證明勝過0050。

下一個模型版本應先固定新聞／價格配對與校準設計，再收集未參與選擇的新觀測：

1. 保留目前凍結V2作追蹤基準；候選價格模型及新聞殘差頭使用同一五股、日期、五日目標與共同帳本，不拿一日Ridge混比。
2. 使用時間交叉擬合建立價格預測的樣本外殘差，新聞只修正公司事件、去重及情緒意外；缺首次取得證據的歷史仍只能探索。
3. 標籤嚴格為次日收盤至第六交易日收盤；全市場日曆隔離六交易日，Scaler只讀訓練視窗。預測校準、門檻與配置只能用較早資料設定。
4. 同一成交、費率、現金及風險限制比較價格／新聞組，分開報預測誤差、交易成本、曝險及成本後績效。誤差改善不直接當成獲利改善。
5. 先保存有限候選與採用規則；已看過歷史不得重新命名為獨立測試。60個成熟訊號日只作運作檢查，效果檢視沿用252執行交易日與時間區塊方法，未通過就保留基準，不自動替換模型。

完整Ridge私人前瞻帳本及收據鏈未交付；網站Saved模式明示不可用，DEMO不補正式資料。歷史訊號的發布前可用性仍缺獨立證據，hash、模型重播一致與樣本數均不能替代它。
