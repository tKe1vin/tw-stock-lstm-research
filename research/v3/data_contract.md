## 每日資料欄位

每個全市場日期與資產各一列；目前資產為 0050 與原五股 2330、2317、2603、2002、2891。

| 欄位 | 定義 |
| --- | --- |
| `Date`, `Ticker` | 台灣市場日期，資產代碼；組合不可重複 |
| `Open`, `High`, `Low`, `Close` | 當日實際名目成交價，**尚未調整分割、股利** |
| `Volume` | 成交股數；可交易列必須大於零 |
| `Stock_Splits` | 當日每一舊股換得的新股數；無事件為 1，0050 分割為 4，長榮減資為 0.4 |
| `Dividends` | 除息日現金股利，每一「當日股數事件後」的股份金額 |
| `Return_of_Capital` | 減資返還現金，每一「事件前舊股」的金額，與一般股利分開 |
| `Dividend_Payment_Date` | 該筆股利實際支付日期；不能把除息日當成可支用現金日期 |
| `Return_of_Capital_Payment_Date` | 減資返還現金的支付日期 |
| `Action_Announcement_At` | 供應商有提供時保留公告時間與 `+08:00`；缺少不補造 |
| `Tradable`, `Suspension_Reason` | 是否有可用實際成交列；停牌必須有逐段來源與原因 |
| `Total_Return_Index` | 從 100 起算的除息日再投資研究財富指數，可由原價和行動重新計算 |

Yahoo 的 `auto_adjust=False` 不保證回傳完全未經分割調整的歷史價格。這次使用 FinMind 名目成交價，並核對 0050 分割前收盤 188.65 元及復牌後 47.57 元。不能再把已調整為四分之一的分割前價格乘四次；程式也拒絕可疑的股數事件報酬。

財富指數在有實際收盤價的事件日使用：

```text
當日含息因子 = [股數因子 × (名目收盤價 + 每新股現金股利) + 每舊股減資退現] / 前期名目收盤價
```

例如長榮 2022 年減資參考價滿足 `0.4 × 187 + 6 = 80.8`。0050 2025 年的一拆四使用官方確切比率 `4`，不把四捨五入後的 `188.65 / 47.16` 當成股數比例。

**此指數採除息日再投資慣例，用於研究標籤；實際資金帳本應在除息日列應收款、支付日才增加可支用現金。** 兩者不可混稱。ETF 管理費已反映於價格，不再重扣；手續費、股票／ETF 不同賣出稅、滑價與股利收款後再投資成本由回測帳本處理。

## 停牌、缺資料與行動日期

不以前值填出可成交價格，也不以各資產日期交集壓縮五交易日標籤。市場日期集合中，已核對停牌的資產保留一列：`Tradable=False`、OHLC 為空、成交量 0。這列只能作明確揭露的停牌估值，不能成交。未有來源的缺列直接拒絕。

FinMind 部分除息資料保留原公告日，即使颱風休市後實際除息交易延後。程式只允許兩筆有來源的明確修正，保留原回應及修正原因：

TWSE `TWT49U` 計算結果表同樣可保留原公告日，不能聲稱該表直接認證了順延後交易日。程式不對任意缺失行動自動套「下一交易日」，其他無報價除息日、未知減資、現金增資或權利認購一律停止，待獨立核對後另立修正。
